# Python Strings Basics

## What is a String?

A string is used to store text in Python.

Example:

```python
name = "Unnati"
```

---

## String Functions I Learned

### len()

Used to count total characters.

Example:

```python
name = "Unnati"

print(len(name))
```

Output:

```text
6
```

---

### upper()

Used to convert text into uppercase.

Example:

```python
name = "Unnati"

print(name.upper())
```

Output:

```text
UNNATI
```
